## About

`Bajaj` contains training notebooks, scripts, outputs, or supporting files for this project area.

## Contents

- `Datasets/`: subfolder.
- `Pre_Train.ipynb`: Jupyter notebook.
- `Pretrained_Models.ipynb`: Jupyter notebook.
- `Training.ipynb`: Jupyter notebook.

## Use

Open the notebooks in Jupyter, VS Code, or Google Colab and run the cells in order after installing the required Python packages.
